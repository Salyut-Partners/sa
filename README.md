# Автосубтитри для вертикальних відео

Кидаєш відео в теку — забираєш із вшитими субтитрами. Локально на Mac,
без хмар і лімітів: розпізнавання через [mlx-whisper](https://github.com/ml-explore/mlx-examples)
на Apple Silicon, вшивання через ffmpeg + libass.

Мову вказувати не треба — вона визначається автоматично, окремо для кожного
файлу, тож ролики різними мовами можна кидати впереміш.

![стилі](inbox/box/_приклад.png)

## Встановлення

Потрібен Mac на Apple Silicon (M1 і новіші).

```bash
git clone https://github.com/forsubs-admin/subs.git
cd subs
./setup.sh
```

Скрипт поставить Homebrew-залежності, збере оточення і перевірить критичне.
Запускати можна повторно — він пропускає те, що вже стоїть.

## Робота

```bash
./run.sh
```

Термінал напише `Слідкую за …/inbox` і залишиться висіти — не закривай його.
Далі кидай відео в підтеку `inbox/<стиль>/`; назва теки визначає вигляд
субтитрів. Готове забирай з `output/`, оригінали переїжджають у `processed/`.

## Стилі

Усі рендеряться капсом, на 24% висоти від низу — вище підпису й кнопок TikTok.
У кожній підтеці `inbox/` лежить `_приклад.png` із виглядом на кадрі.

| Тека | Вигляд |
|---|---|
| `yellow` | 4 слова на екран, активне жовтим — базовий |
| `green` | 3 слова, крупніше, активне салатовим |
| `red` | те саме, активне червоним |
| `box` | активне слово на чорній заокругленій плашці |
| `one-word` | по одному слову, найкрупніше |
| `simple` | статичні рядки, без підсвітки |

Параметри — словник `STYLES` на початку [`technical/subtitle_styler.py`](technical/subtitle_styler.py).
Усі розміри відносні до кадру, тож вигляд однаковий на 720p і 1080p.
