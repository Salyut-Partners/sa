# Комплаєнс за плейбуком

Вердикт завжди з id правила з `playbook/compliance/`. Вигаданих id не буває:
якщо жодне правило не підходить — так і кажи, без посилання. Правила плавають
кожні 2–3 місяці, остаточний вердикт виносить платформа — про це скажи
наприкінці одним рядком.

## Що читати

1. `playbook/compliance/rules-index.md` — карта 33 правил, читається завжди.
2. Потім лише ті файли `CMP-*`, на які вказує карта для цього типу тексту:
   - скрипт, субтитри, написи на макеті → `playbook/compliance/creatives/`;
   - стаття → `playbook/compliance/articles/`;
   - фінансова вертикаль → спершу CMP-030, CMP-031, CMP-032, потім решта.
3. Розділ (g) `playbook/rules.md` — п'ять головних заборон і словник тригерів
   (instant/fast, free, relocate, «за хвилину», «сьогодні», «доступні вакансії»).

Не відкривай усі 33 файли: карта каже, які саме. Нотаток `trigger-words`,
`first-person-ban` та інших нотаток волта тут немає — правила про них уже
згорнуті в розділ (g) плейбука; посилайся на CMP-id, не на назви нотаток.

## Як перевіряти

Пройди текст речення за реченням і для кожного порушення дай рядок:

```
❌ «мене прийняли на роботу» — перша особа. CMP-033 → «Швейцарія наймає».
⚠️ «дізнайся за хвилину» — швидкість в інформаційній частині, 100% реджект. CMP-011/CMP-013 → «дізнайся, як це працює».
✅ «зарплата й страховка в джобсах» — дозволено (розділ (g), практика).
```

Порядок перевірки для креативу: перша особа (CMP-033) → дієві CTA й інструкції
клікати (CMP-002, CMP-005, CMP-014) → обіцянка виконується на лендінгу
(CMP-001, CMP-003, CMP-004, CMP-015) → видавання себе за іншого (CMP-016,
CMP-017) → час і швидкість (CMP-010, CMP-011, CMP-013) → ціни (CMP-008,
CMP-009) → гео (CMP-007) → формат (CMP-006, CMP-012).

Для статті: відповідність куту (CMP-020, CMP-028) → якість тексту (CMP-021,
CMP-022, CMP-023) → перший абзац і заголовок (CMP-024, CMP-025, CMP-026) →
джерела й медіа (CMP-027, CMP-029).

Після кожного перекладу перечитуй — модель повертає першу особу назад.

## Що віддати

1. Список порушень із id, як вище; без порушень — «порушень за правилами
   CMP-001…033 не бачу» і те, що вердикт за платформою.
2. Виправлений текст цілком, якщо байер просив переписати, — тим самим тоном,
   освітнім, без «я».
3. Якщо це реджект із платформи — зістав текст `additional_rejection_reasons`
   із правилами й назви, який файл або фразу міняти; у таблиці заливів такий
   файл уже підписаний як вирізаний.

## Чого не робити

- Не цитувати правил, яких немає в `playbook/compliance/`.
- Не запускати `sa apply` і не змінювати нічого на платформі.
- Не правити файли в `launches/` без прохання — вердикт спершу, правка потім.
