# 23 — `sa adopt`: топік, створений руками

**What to build:** `sa adopt <topic-id> --key <launch-key>` створює теку заливу з наявного топіка платформи: `topic.yaml` (назва, internal name, launch key, сайт, кабінети з джерелом із довідника й пікселями), `termgroups/<tg>/keywords.txt` з живих ключів, `articles/<a>/article.md` зі статей (HTML → markdown, картинки в `images/`), `state.json` з id топіка, конфігурації, термгруп і статей. Наявні кампанії топіка не підхоплюються — кампанії починаються з нової матриці через `sa expand`. `state.json` тримає відбиток вмісту кожної підхопленої сутності; `plan` порівнює файл із відбитком, а не з платформою, тож одразу після `adopt` план порожній. Тікет у ClickUp з'являється звичайною звіркою.
