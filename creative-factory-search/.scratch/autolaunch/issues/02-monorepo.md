# 02 — Монорепо `~/sa`

**What to build:** байер запускає `claude` у `~/sa` і бачить волт, скіл, редактор, субтитри й папки заливів в одному місці, а оновлює все одним `git pull`. Три репозиторії (`creative-factory-search`, `sa-knowledge`, `subs`) переїжджають через `git subtree` зі збереженням історії. Кореневий `CLAUDE.md` маршрутизує до правил пошуку волта, а не дублює їх. Корінь заливів — параметр конфігурації `sa` з дефолтом усередині `~/sa`, поза git. Робочі теки субтитрів (`inbox`, `output`, `processed`) теж поза git.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `git log` у монорепо показує історію всіх трьох джерел
- [ ] Тести й typecheck редактора зелені після переїзду, без змін у самому коді
- [ ] Кореневий `CLAUDE.md` веде до `CLAUDE.md` волта; правила пошуку не скопійовані
- [ ] Конфігурація `sa` має `launches_root`; тека за замовчуванням створюється й ігнорується git
- [ ] Вотчер субтитрів запускається зі свого нового місця тією самою командою
