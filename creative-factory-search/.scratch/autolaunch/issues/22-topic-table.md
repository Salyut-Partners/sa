# 22 — Таблиця топіка: групування, три стани, «Що буде залито»

**What to build:** таба «Заливи» стає таблицею топіка: зліва топіки, справа для обраного — джерело → кабінет → кампанії й рядок «загалом по топіку» (кампаній, зібраних, активних, з реджектом, без креативів). На кампанію три стани й нічого більше: диск (креативи, скрипт, валідний yaml), залив (не зібрана / зібрана / є різниця), платформа (статус білдера й кампанії, причина реджекту, посилання в адмінку). Сервер опитує `GET /campaign-builder?user_id=` у фоні раз на кілька хвилин і при відкритті топіка — один запит на байера, не на топік; відповідь зіставляється з `state.json` за id білдера. Реджекти мінімум: причина в рядку, у плані перезаливу файли з `non_compliant` від ревʼю-бота позначені як вирізані; файли не переносяться, тікет не коментується. Дві кнопки замість «Залити»: «Що буде залито» на топіку й на кампанії відкриває план із галочками й заголовком «Нічого ще не зроблено»; «Залити N кампаній» внизу плану робить `apply`; для перезаливу «Що буде перезалито» → «Перезалити N». Кнопка «оновити план» зникає: план перечитується від вотчера диска й від нового статусу платформи. З рядка пачки в `sources/` відкривається редактор.

**Blocked by:** 18 — Маніфести під матрицю; 19 — Ісходники.

**Status:** done (2026-09-11) — `core/topic-table.ts` (три стани, групування, «загалом», `launchable`), вердикти бота й вирізання `non_compliant` у `core/campaign-plan.ts`, `narrowPlan`/`campaignOutline` на список кампаній, `server/platform-status.ts` (два GET на байера: `/campaign-builder?user_id=` і `/v2/campaigns?user_id=`, кожні 5 хв, після apply і при відкритті топіка, з версією в дереві), роут `POST /api/launches/:key/table`, таба переписана (топіки зліва, таблиця, план із галочками, «Залити N — за живі гроші», без «оновити план», ісходники відкриваються в редакторі). Примітки: (1) глибокий маршрут адмінки до білдера в дампах відсутній (SPA), тож посилання веде на адмінку з id білдера поруч; (2) під час smoke-тесту 2026-09-11 ~17:10 платформа відповідала 500 на всі GET — таблиця показала «платформа ще не опитана» і не впала; (3) `platform.user_id` у конфігурації необов'язковий, без нього id береться з першого топіка байера на платформі.
