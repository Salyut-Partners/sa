# 18 — Маніфести під матрицю: джерело на кабінеті, `sa expand`, `sa new campaign`

**What to build:** матриця заливу — разовий генератор папок, не файл на диску. `sa expand <key>` читає JSON зі stdin (осі: термгрупи з ключами, статті, пари мова+гео, кабінети; перевизначення на клітинку: бід, бюджет, стаття, `name`) і створює всі відсутні папки за раз: `termgroups/<tg>/keywords.txt`, `articles/<a>/article.md`, `campaigns/<name>/campaign.yaml` + порожній `script.md`. Наявні папки не чіпає, нічого не видаляє, звітує «створено N, пропущено M». `sa new campaign <key> --termgroup --article --language --country --account [--name]` створює одну. Імена папок кампаній складає `sa`: `<language>-<country>-<account>-<termgroup>-<article>` у нижньому регістрі, `name` у клітинці перевизначає. У `topic.yaml` поле `traffic_source` зникає, кожен кабінет несе `source: tiktok|facebook`; `campaign-plan` бере джерело з кабінету кампанії для креативів, TSP і builder. Кореневий `CLAUDE.md` пояснює: структуру створює `sa expand`/`sa new campaign`, Claude пише лише вміст. Два наявні заливи Артема переносяться руками.
