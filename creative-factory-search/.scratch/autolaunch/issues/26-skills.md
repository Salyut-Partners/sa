# 26 — Нові скіли на базі матриці

**What to build:** скіли `~/sa/.claude/skills/`, написані з нуля під плейбук і матрицю, замість архівованих скілів волта: «обговори матрицю» (інтейк топіка, ключів, гео, кабінетів по плейбуку → JSON для `sa expand` → виклик → звіт), «комплаєнс» (скрипт, стаття, написи по `playbook/compliance/`), «залив» (від теки з креативами до «Що буде залито», без `--confirm`).
