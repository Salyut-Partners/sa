# 29 — «Рахувати план» у фоні

**What to build:** розрахунок плану на табі «Заливи» зараз живе у вкладці й
губиться, щойно байер іде на «Креативи» чи «Субтитри». План рахує сервер: кнопка
ставить розрахунок для топіка, таба лише показує його стан. Повернувся — бачиш
прогрес або готовий план; повторне натискання поки рахується не запускає другий.
Результат живе, доки теку чи платформу не опитано наново.

**Status:** done (2026-09-29) — `server/plans.ts`: підрахунок по топіку живе на сервері, повторне натискання приєднується до поточного, результат тримається проти теки, для якої його рахували. `POST /api/launches/:key/table` з `count: true` запускає підрахунок і одразу відповідає; кожне читання несе `planCounting`. Таба опитує кожні 1.5 с, поки рахується, а панель плану відкривається знову, коли повертаєшся на таб. Наживо на `ai-jobs-de-wh`: читання без `count` бачили «рахується», за ~14 с — готовий план.
