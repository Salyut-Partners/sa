# 02 — Новий сет, компактний блок, командні дефолти

PRD: `.scratch/prd-quick-launch.md`

**What to build:** у списку сетів — «+ Новий сет» із селектами термгрупи й
статті топіка з платформи. Для нового сету бюджет і бід беруться з останньої
кампанії топіка, далі командний дефолт 20 / 0.45; «Launch tomorrow» увімкнено;
країна порожня. Піксель: остання кампанія сету → остання кампанія топіка →
піксель ніші (ніша — з назви топіка й назв пікселів), з яким байер востаннє заливав; немає —
порожньо, байер вибирає зі списку пікселів з ендпоінта платформи. Решта полів —
TikTok, language All, RSOC 6, піксель, тема, headline, ротація ключів, вік /
стать / пристрої / ОС, end date, розклад — видно компактним блоком дрібним
шрифтом; «Редагувати» розгортає його в поля, правки діють лише на цей залив.
RSOC перевіряється проти `/rsoc-counts`. Топік без термгрупи або статті —
підказка «налаштуй на платформі», кнопка неактивна. Командні дефолти
постачає `setup.sh` у конфіг.
