# База знань Search Arbitrage

Кореневий навігаційний хаб. Читай звідси, а не скануй усі нотатки.

## Розділи

- **`knowledge/`** — дистильовані знання: платформа, збірка зв'язки, аналітика.
  Карта: [[knowledge-map]].
- **`bundles/`** — зв'язки: запущені комбінації з результатом. Росте щотижня.
- **`compliance/`** — 32 правила провайдера. Карта: [[rules-index]].

## Точки входу

- [[onboarding]] — маршрут читання для новачка, по порядку.
- [[CONTEXT]] — глосарій: що саме означають «зв'язка», «кут», «підхід», «скрипт».
- [[rsoc-model]] — модель бізнесу; з неї випливає решта.

## Надійність

Кожна нотатка-знання несе поле `status`. Порядок довіри:

| Значення | Що означає |
|---|---|
| `перевірено-практикою` | наші запуски підтвердили |
| `зі-слів-партнера` | сказав провайдер, самі не перевіряли |
| `гіпотеза` | здогад або deep-research, не підтверджено |
| `застаріле` | колись працювало, лишається для історії |

Зв'язки замість `status` несуть `outcome`: `зайшла` або `злила`. Злиті записуються
лише тоді, коли відома причина — саме причина в них і цінна.

## Протухання

Ніде не записується, рахується при читанні. Зв'язка старша **3 місяців** або знання
старше **6** — привід перевірити актуальність, перш ніж на них спиратися.
