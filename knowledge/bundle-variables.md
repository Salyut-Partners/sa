# Зв'язка: чотири змінні й пули кампаній

Робоче визначення партнера — те, за яким команда рахує кампанії.

## Визначення ментора

> Зв'язка = **підхід + гео + скрипт + мова**

Чотири змінні. Офер при цьому лишається той самий.

Глосарій бази ([[CONTEXT]]) описує зв'язку з боку матеріалу — ключі, стаття,
креативи. Це не суперечність: там про те, **з чого вона складається**, тут про
те, **що робить її іншою зв'язкою**.

## Унікалізація по одній змінній

Змінюєш **одну** змінну — отримуєш окремий пул із двох-трьох кампаній.

| Що змінив | Результат |
|---|---|
| Франція + французька | пул 3 кампанії |
| та сама Франція, але арабська (мігранти) | ще 3 кампанії |
| змінив підхід | ще 3 кампанії |
| змінив скрипт | ще 3 кампанії |

Так із однієї теорії розгортається обсяг, не змішуючи змінні.

## Стеля на акаунт

**Максимум 2–3 кампанії на зв'язку в межах одного акаунта.** Золота середина —
дві-три, і партнер прямо каже: **чим менше, тим краще.**

Розподіл акаунтів під зв'язки: [[account-strategy]].
