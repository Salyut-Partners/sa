# Ланцюг збірки зв'язки на платформі

Порядок елементів, які треба створити, щоб запустити кампанію. Кожен наступний
підв'язується до Topic. Контекст: [[platform-ironfli]].

Повний прохід ланцюга займає **7–8 хвилин** одним байером. Далі, коли зв'язка
натестована, нові запуски йдуть копіюванням готових елементів.

## Порядок

1. **Topic** — коренева папка, зв'язуючий елемент усього. Нейминг: скорочення
   команди + нік байера + офер + опційно гео. Два поля: `Topic Name` (з
   пробілами) і `Topic Internal Name` (системний, без пробілів).
2. **Configurator / Traffic Source** — джерело, з якого заливаємо. Під один
   Topic можна підв'язати кілька джерел. Спеціальні аудиторії під TikTok і FB
   не ставимо.
3. **Term Groups** — ключові слова. Деталі: [[term-groups-keys]].
4. **Стаття** — монетизація, домен, текст. Деталі: [[article-setup]].
5. **Creative Repository** — креативи + транскрибація. Деталі:
   [[creatives-and-script]].
6. **Headline** — заголовок оголошення.
7. **Traffic Source Profile** — налаштування асету: гео, бюджет, бід.
   Деталі: [[traffic-source-profile]].
8. **Campaign Builder** — фінальна збірка. Деталі: [[campaign-builder]].

## Нейминг має значення для аналітики

Продумай структуру нейминга **до того**, як кампаній стане 200. Саме з нього
потім витягується аналітика — зокрема коли аналіз робиться моделлю по
експортованому CSV ([[analytics-tracker]]).

База: нейминг команди + офер + гео. Кастомні приписки вітаються.

## Копіювання замість створення заново

Traffic Source Profile можна скопіювати й змінити лише гео чи мову — швидше,
ніж проходити ланцюг наново. Так само з кампаніями після реджекту:
[[moderation-statuses]].
