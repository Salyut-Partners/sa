# Старт тут

Цей гайд — для байера, який тільки заходить у Search Arbitrage. Він пояснює
модель, платформу й логіку зв'язки й дає орієнтири для першого заливу. Цифри в ньому
взяті з менторства партнерів. Це точка, від якої відштовхуєшся, а не закон.

Налаштування робочого місця (редактор, токени, `sa`) — окремо, в `ONBOARDING.md`
у репозиторії `~/sa`.

## Маршрут на перший тиждень

| День | Що зробити |
|---|---|
| 1 | Прочитати «Що таке Search Arbitrage» і «Платформа». Подивитись відео з навчання платформи. |
| 2 | «Логіка зв'язки» і «Ключі й виплати» — головне, від чого залежать гроші. |
| 3 | «Вертикалі» й «Compliance». Відкрити ColdSpy і пройти рецепт із розділу «Spy». |
| 4 | «Матриця заливу» — зібрати перший тестовий залив за шпаргалкою. |
| Далі | Повертатися до матриці й compliance щоразу перед заливом. |

Не зрозуміло або є питання — питай Claude: у `~/sa` він читає цей самий
плейбук. Без `~/sa` натисни «Скопіювати для Claude» вгорі сторінки й встав
текст у будь-який чат.

## Глосарій

| Термін | Що означає |
|---|---|
| **RSOC** | Related Search on Content — блок пошукової реклами Google усередині статті. Клік по ньому приносить гроші. |
| **Провайдер** | Компанія з доступом до фіду RSOC, яка дає домени, статті й платить нам. У нас — IronFli, кабінет digifor. |
| **Зв'язка** | Узгоджений ланцюг «креатив → стаття → група ключів» під одну тему й гео. |
| **Підхід / кут** | Під яким соусом подається тема: «робота на складі для мігрантів», «кредит для безробітних». |
| **Топік** | Коренева папка зв'язки на платформі. Під нього підв'язуються ключі, стаття, креативи. |
| **Термгрупа** | Група ключів (до 10), яку ми пропонуємо Google для видачі у статті. |
| **Ключ** | Пошуковий запит, під яким рекламодавець купує показ. Від нього залежить, скільки платять за клік. |
| **Видача** | Блок ключів на статті, по яких клікає людина. |
| **Виплата / RPC** | Скільки провайдер платить нам за клік по видачі. Видно тільки середню, не по кожному ключу. |
| **Закупка / CPC** | Скільки ми платимо TikTok чи Facebook за клік на статтю. |
| **Бід** | Ставка, яку ми даємо в аукціоні джерела трафіку. |
| **Косткап** | Бід-стеля: джерело не платить за результат дорожче за неї. |
| **Мікроспенд** | Кампанія пройшла модерацію, але майже не витрачає — бід не пробиває аукціон. |
| **ROI** | (ревеню − спенд) / спенд. Головна метрика разом із середньою виплатою. |
| **S-clicks / G-clicks** | Ліди (люди, що клікнули видачу) / івенти (усі кліки по ключах). Один лід може дати кілька оплачуваних кліків. |
| **Траст домену** | Довіра Google до домену. Новий домен платить гірше й гріється місяцями. |
| **T1 / T2 / T3** | Тіри гео: дорогі багаті країни (CH, DE, UK…) / середні / дешеві (Латам, Азія, Африка). |
| **Реджект** | Відмова модерації провайдера з причиною. Це фідбек, а не вирок. |
| **Скейл** | Масштабування робочої теорії новими кампаніями поверх, а не підняттям бюджету. |
| **Спай** | Підглядання за тим, що ллють інші: ColdSpy, AdPlexity, TikTok-стрічка, FB Ad Library. |
