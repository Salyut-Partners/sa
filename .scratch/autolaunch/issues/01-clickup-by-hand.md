# 01 — ClickUp руками (E0)

**What to build:** тімлід відкриває борду й бачить, хто над чим працює. Спейс «Заливи», папка на команду, у кожній листи «Заливи» й «Тиждень»; кастомні поля тікета `launch_key`, `вертикаль`, `гео`; тег `design` і в'ю рівня воркспейсу, яке збирає всі задачі з цим тегом у чергу дизайнера; шаблон тікета плану на тиждень. Усе руками в ClickUp, без коду. На виході — id спейса, листів і кастомних полів, які потрібні тікету 03.

**Blocked by:** None — can start immediately.

**Status:** manual — робить Артем, не агент

- [ ] Спейс «Заливи» з папкою хоча б однієї команди й двома листами існує
- [ ] Три кастомні поля створені й видимі на тікеті
- [ ] Тег `design` і в'ю черги дизайнера показують сабтаску, створену під тікетом заливу
- [ ] Шаблон тікета «план на тиждень» створений
- [ ] Id спейса, листів і полів записані туди, де їх візьме конфігурація `sa`
