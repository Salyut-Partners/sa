# Шрифти

`MontserratSubs.ttf` — статичний ExtraBold, зібраний з варіативного Montserrat
скриптом `../make_font.py`. Потрібен окремий файл, бо варіативний Montserrat має
дефолтний інстанс Thin, і libass рендерить субтитри тонкими попри `Bold=1`.

Montserrat поширюється за SIL Open Font License 1.1 — текст у `OFL.txt`.
Ліцензія дозволяє поширення похідних; згенерований файл зберігає її
у власних метаданих (записи name 13/14).

Статичні шрифти можна класти сюди як є — `make_font.py` потрібен лише
для варіативних.
