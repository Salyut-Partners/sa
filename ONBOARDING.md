# Онбординг

Одна сторінка: що поставити, куди покласти токени, і з чого почати. Решту —
«як влаштований код», «де плейбук» — читай з `CLAUDE.md`.

## 1. Встановлення

```sh
git clone https://github.com/Salyut-Partners/sa.git ~/sa
cd ~/sa && claude
```

і напиши Claude: **«встанови все необхідне»**. Скіл `setup` сам запустить
`./setup.sh`, попросить токени (розділ 2), впише їх і перевірить живцем.
Без Claude — те саме руками: `./setup.sh`, потім розділ 2.

Один скрипт ставить усе: Node, ffmpeg, залежності редактора, субтитри (другий
ffmpeg, Python 3.11, шрифт) і шаблон конфігурації. Ганяти можна повторно —
кожен крок, що вже стоїть, пропускається, а не переставляється. Якщо щось не
вийшло (наприклад субтитри на Intel Mac), скрипт каже, що саме, і йде далі:
редактор і залив не залежать від субтитрів.

Наприкінці скрипт сам каже, чи заповнено токен платформи.

## 2. Токени

Скрипт уже поклав шаблон у `~/.config/sa/config.json` зі спільним id
команди (`organization_id`). Заповни свій токен:

```json
{
  "sources_root": "~/sa/sources",
  "platform": { "token": "…", "organization_id": 121 }
}
```

- **`platform.token`** — Bearer на платформі digifor (DevTools на
  admin.digifor.io → Network → заголовок `Authorization`). Особистий — виклики
  йдуть з твого акаунта і твого IP. Хто ти на платформі, сервер бере з самого
  токена. Необов'язкове **`platform.user_id`** лишається як ручне
  перевизначення.
- **`sources_root`** — куди після заливу лягають фото, з яких зроблено
  креативи: тека на топік. Можна не чіпати.
- Необов'язкове **`launch_defaults`** — свої значення замість командних
  (`budget`, `bid`, `bid_step`, `launch_tomorrow`, `identity`, `rsoc_count`,
  `theme`, `headline`, `keyword_rotation`, `source`, `language`, `gender`,
  `age`, `devices`, `os`). Без нього — RSOC 6, 25 / 0.3, крок біда 0.05 між
  кампаніями заливу, старт сьогодні, FP «Good Life» на кабінетах GB, темна
  тема, «Learn more», TikTok, таргетинг All.

Ключі редактора — спільні командні, у тімліда: `ELEVENLABS_API_KEY`
(озвучка) і необов'язковий `DEEPL_API_KEY` (переклад скрипту) у
`creative-factory-search/.env`; шаблон поклав той самий скрипт. Ключ
ElevenLabs — з правом Voices: read (ElevenLabs → Developers → API Keys), інакше
редактор показує лише стандартні голоси.

Без токена нічого не ламається: редактор працює й експортує в «Завантаження»,
пункту «Залити» в «Куди» просто немає; `sa topics` скаже, чого бракує.

## 3. Перший запуск

```sh
cd creative-factory-search
npm run dev                                    # редактор на 5181, сервер на 5180
```

Відкрий <http://localhost:5181>.

## 4. Перший залив

Топік, термгрупи й статті заводяться руками в адмінці платформи — Claude
допоможе з текстами й комплаєнсом (`sa topics`, `sa show <топік>` він читає
сам).

У вкладці «Креативи»: фото, озвучка, мови. Праворуч «Куди» → «Залити на
платформу». Вибери топік і сет (термгрупа + стаття) — країна, бюджет, бід і
старт підставляться з останньої кампанії сету. Кабінет вибирається щоразу
сам. Відміть креативи; mp4 дизайнера додається кнопкою або перетягуванням.

«Залити» показує підсумок, «Підтвердити» заливає за живі гроші: рендер, що
змінився, завантаження, headline, TSP, нова кампанія з посиланням. Упав крок —
він червоний з поясненням і кнопкою «Спробувати ще»; завантажене вдруге не
вантажиться, а до останнього кроку нічого оплачуваного не створюється.
