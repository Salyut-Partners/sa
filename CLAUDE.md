# ~/sa — робоче місце байера

Один репозиторій, три частини:

```
setup.sh                   одна команда встановлення й оновлення: Node, ffmpeg, subs
creative-factory-search/   редактор креативів із заливом, сервер, CLI `sa` (лише читання) — код і його README
playbook/                  правила байера: rules.md (вижимка) і compliance/ (правила провайдера)
subs/                      автосубтитри: вотчер над inbox/, стилі, пайплайн; таба в редакторі кличе його ж
```

Поза git: `~/.config/sa/config.json` (токен платформи, `sources_root`,
`launch_defaults`) і `sources_root` — ісходники заливів, тека на топік
(за замовчуванням `~/sa/sources`).

## Куди йти за чим

- **Новий байер, установка, токени** — `ONBOARDING.md`; «встанови все
  необхідне» — скіл `setup`.
- **Як заливати: зв'язка, біди, стоп, скейл, обсяг** — `playbook/rules.md`,
  дві тисячі слів, читається цілком перед розмовою про зв'язки. Кожне
  правило несе позначку надійності — називай її байеру.
- **Чи пройде формулювання модерацію** — `playbook/compliance/rules-index.md`
  і правила `CMP-*` поруч; вердикт завжди з id правила, вигаданих id не буває.
- **Як влаштований код, його правила і як його запускати** —
  `creative-factory-search/README.md`, розділ «Shape of the code».
- **Субтитри** — `subs/README.md`; технічні граблі — `subs/technical/README.md`.
- **Що будуємо і чому** — `creative-factory-search/.scratch/prd-quick-launch.md`,
  тікети поруч у `.scratch/quick-launch/issues/`. `prd-autolaunch.md` — історія.
- **Скіли** — `.claude/skills/`: `setup` (`setup.sh`, токен, перевірка),
  `compliance` (вердикт з id `CMP-*` по плейбуку). Написані під плейбук, у
  волт не ходять.

## Як іде залив

Софт без стану: ні тек заливу, ні файлів стану — щоразу читається платформа.

1. Статті, термгрупи, ключі, ваги, топіки й авто-правила байер налаштовує
   руками в адмінці платформи. Claude допомагає з текстами й комплаєнсом:
   `sa topics` — топіки байера, `sa show <topic>` — термгрупи з ключами й
   вагами, статті текстом, сети з останньою кампанією.
2. Креатив робиться у вкладці «Креативи» редактора. «Куди» → «Залити»:
   топік, сет (термгрупа + стаття), креативи (рендери всіх мов з галочками і
   mp4 з диска), кабінет, країна, бюджет, бід, «Launch tomorrow»; решта —
   компактним блоком із командних дефолтів.
3. «Залити» → модалка з підсумком → «Підтвердити» — це робить лише людина.
   Редактор рендерить, що змінилося, вантажить креативи, headline, TSP і
   створює нову кампанію; старі не чіпаються. Після успіху фото — у
   `sources_root/<топік>/`.

## Правила

- Мова спілкування — українська; код, коміти й імена файлів — англійською.
- Claude на платформу не пише ніяк: `sa` лише читає, а маршрут заливу
  сервера (`/api/launch`) — для кнопки в редакторі, не для Claude;
  `.claude/settings.json` забороняє звертатися до нього з shell. Статті й
  ключі, які ви з байером написали, він вносить в адмінку сам.
- Волта в цьому репозиторії більше немає: не шукай `sa-knowledge/`, не
  вигадуй нотаток. Що не сказано в плейбуку — так і скажи байеру.
