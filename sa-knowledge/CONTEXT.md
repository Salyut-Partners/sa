# Search Arbitrage — база знань

Спільна мова команди Search Arbitrage та бази знань, з якої байери брейнштормлять
гіпотези. Цей файл — тільки глосарій: без схем, полів і рішень щодо реалізації.

## Мова

**Зв'язка**:
Одиниця, якою росте база: конкретна запущена комбінація ключів, статті й креативів
під певну вертикаль, гео та мову — разом із тим, що з неї вийшло. Один запис у базі =
одна зв'язка.
_Уникати_: кейс, бандл, підхід

**Кут**:
Варіація зв'язки, де змінюється персонаж чи аудиторія й трохи підганяються
стаття з ключами: дівчина / бабуся / молода пара; безробітні / мігранти.
Кути живуть усередині однієї зв'язки, окремими записами в базі не стають.
_Уникати_: angle, заход

**Скрипт**:
Текст, який звучить у відео — те, що транскрибується з креативу.
_Уникати_: сценарій, озвучка, текст креативу

**Байер**:
Учасник команди, який запускає зв'язки й брейнштормить нові гіпотези на базі
знань. Основний споживач бази.
_Уникати_: медіабайер, користувач, співробітник

**Волт**:
Дистильована база знань — тека нотаток у форматі Obsidian, яку читає Claude Code
і за потреби переглядає людина. Містить тільки видушену суть, не сирі матеріали.
_Уникати_: база даних, KB, knowledge base, сховище

**Сире джерело**:
Первинний матеріал, з якого видушується нотатка: транскрипт сесії, документ
провайдера, deep-research. Живе поза волтом; зв'язок тримає поле `source`.
_Уникати_: сирець, транскрипт, першоджерело

**Фасет**:
Поле в front-matter із закритим словником значень, за яким база фільтрується
пошуком. Основний механізм пошуку у волті — на відміну від лінків, які працюють
лише другим кроком, коли нотатку вже знайдено.
_Уникати_: тег, атрибут, метадані, property

**Онбординг-маршрут**:
Нотатка з упорядкованим списком лінків на існуючі нотатки — порядок читання для
новачка. Не окрема тека й не копія знань.
_Уникати_: онбординг-папка, навчальні матеріали, курс
