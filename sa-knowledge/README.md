# База знань Search Arbitrage

Це база знань команди. Ти працюєш із нею через чат — питаєш звичайною мовою, асистент
шукає відповідь у базі й відповідає.

Питати можна як зручно: українською, російською, суржиком. База українською, але
асистент перекладає сам.

## Постав собі асистента

Потрібно раз, хвилин на десять.

**1. Claude Code**

Підписка Claude Pro ($20/міс) і сам застосунок:

```bash
npm install -g @anthropic-ai/claude-code
```

Далі запусти `claude` і залогінься своїм акаунтом Claude.

**2. GitHub**

Потрібен акаунт GitHub і `gh` — через нього асистент відкриватиме запити на додавання
записів у базу.

```bash
brew install gh      # macOS
gh auth login
```

Скажи куратору свій нік на GitHub — він видасть доступ на читання.

**3. База**

```bash
git clone <адреса-репозиторію> sa-knowledge
cd sa-knowledge
claude
```

Усе. Асистент сам підтягує свіжу версію бази щоразу, коли ти запускаєш `claude` у цій
теці — окремо оновлювати нічого не треба.

**4. Obsidian — за бажанням**

Якщо хочеш дивитися базу очима, а не тільки питати: постав [Obsidian](https://obsidian.md),
натисни *Open folder as vault* і вибери теку `sa-knowledge`. Налаштовувати нічого не
треба. Для роботи це не обов'язково.

## Що можна робити

| Хочеш | Просто скажи |
|---|---|
| Знайти щось у базі | «що в нас є по кредитах у Польщі?» |
| Обговорити ідею | «знайшов на спаї таке-то, що думаєш?» |
| Перевірити скрипт | «перевір цей скрипт на комплаєнс» |
| Зробити креативи | «зроби промти під цей бриф» |
| Записати результат | «додай зв'язку» |

## Правила

База **тільки для читання.** Ти не можеш змінити нотатку напряму — і асистент не
стане цього робити, навіть якщо попросиш. Нові записи додаються через запит на
додавання, який рев'юїть куратор.

Помітив помилку в базі — скажи куратору.

## Якщо щось не працює

- `gh: command not found` → постав `gh` (крок 2)
- «не бачу репозиторій» → куратор ще не видав доступ, напиши йому
- Асистент відповідає не по базі → перевір, що запустив `claude` **усередині** теки
  `sa-knowledge`, а не деінде
