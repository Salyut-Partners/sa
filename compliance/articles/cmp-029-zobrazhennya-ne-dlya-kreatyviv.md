# Зображення й відео в статті — для підтримки, не для додаткових креативів

Платформа дозволяє вставляти в статтю зображення й відео. Їхнє призначення —
підкріпити те, що обіцяв фронтенд-креатив.

Це **не місце** для розміщення додаткових рекламних креативів.
