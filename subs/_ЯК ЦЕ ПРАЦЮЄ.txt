Якщо ставиш це вперше на новий Mac — гортай униз, до розділу
ПЕРШЕ ВСТАНОВЛЕННЯ. Якщо вже все стоїть — читай з початку.


ЯК ЗАПУСТИТИ
Відкрий Термінал і встав один рядок:

    cd ~/subs && ./run.sh

Якщо тека лежить не в ~/subs, а деінде (наприклад розпакував у Завантаження) —
підстав свій шлях: cd ~/Downloads/subs && ./run.sh
Найпростіше: набери в Терміналі "cd " (з пробілом) і перетягни теку subs
у вікно Термінала — шлях підставиться сам.

Мову вказувати не треба — вона визначається сама, окремо для кожного відео.
Можеш кидати англійські, українські й польські ролики впереміш.

Термінал напише "Слідкую за .../subs/inbox" і зависне — так і має бути,
НЕ ЗАКРИВАЙ його. Зупинити — Ctrl+C у тому ж вікні.
Поки вікно закрите, відео в теках просто лежать і нічого не відбувається.


ЯК ОНОВИТИСЬ
Коли виходять нові стилі чи виправлення:

    cd ~/subs && git pull && ./setup.sh

Другу команду не пропускай: git оновлює код, але не бібліотеки.


ЯК КОРИСТУВАТИСЬ
Кидай відео в підтеку — вона визначає стиль субтитрів.
У кожній підтеці лежить _приклад.png: як цей стиль виглядає на кадрі.

Усі стилі — КАПСОМ.

  yellow    — 4 слова на екран, активне жовтим (базовий)
  green     — 3 слова, крупніше, активне салатовим
  red       — 3 слова, крупніше, активне червоним
  box       — активне слово на чорній заливці (як у топових акаунтів)
  one-word  — по одному слову, найкрупніше
  simple    — статичні рядки по 7 слів, без підсвітки

Відео, покладене просто в inbox (не в підтеку), обробиться стилем
за замовчуванням — yellow.

У терміналі видно, яку мову воно визначило: "визначена мова: en".
Якщо ролик починається з музики чи довгого мовчання і мова вгадалась не та —
запусти того разу з явною мовою: ./run.sh uk

Готове забирай у subs/output/, оригінали переїжджають у subs/processed/.


================================================================
ПЕРШЕ ВСТАНОВЛЕННЯ (один раз на новий Mac)
================================================================

НАЙПРОСТІШЕ: віддай цей файл Клоду (Claude Code в Терміналі або Claude в
браузері) і напиши "постав мені це, зроби все сам". Він виконає кроки нижче,
підставить правильні шляхи під твій Mac і полагодить, якщо щось відвалиться.
Далі — ті самі кроки вручну.

Потрібен Mac на Apple Silicon (M1 і новіші). На процесорах Intel не працює.

0) З'ясуй, ДЕ насправді лежить тека subs. Якщо розпакував у Завантаження —
   це ~/Downloads/subs, і всі команди нижче треба писати з цим шляхом.

1) Homebrew (якщо ще немає):

   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2) Нормальний Python. Системний Python від Apple НЕ вміє створювати
   віртуальні оточення — на цьому кроці все й спотикається:

   brew install python@3.11

3) ffmpeg — потрібні ОБИДВА, це не помилка:

   brew install ffmpeg
   brew install ffmpeg-full

   Звичайний ffmpeg зібраний БЕЗ libass, тому вшивати субтитри не вміє.
   А ffmpeg-full не потрапляє в PATH, тому розпізнавалка його не бачить.
   Один читає аудіо, другий малює субтитри.

4) Шрифт:

   brew install --cask font-montserrat

5) Оточення й бібліотеки (шлях підстав свій):

   cd ~/subs/technical
   /opt/homebrew/bin/python3.11 -m venv .venv
   ./.venv/bin/pip install mlx-whisper fonttools

6) Зібрати жирний шрифт для субтитрів:

   ./.venv/bin/python make_font.py

7) Перший запуск. Модель розпізнавання (~1.5 ГБ) качається один раз,
   тому перше відео обробляється довше:

   cd ~/subs && ./run.sh

Якщо на якомусь кроці вилізла помилка — скопіюй її текст і покажи Клоду
разом із цим файлом, він розбереться.
